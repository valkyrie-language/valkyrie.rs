# ✨ `@valkyrie-language` v0.0.2

## ✨ Features

- **Legion 单脚本项目**：根目录 `.v` 可携带嵌入 manifest，无需 `test/` 或完整工程布局即可 `legion test` / `legion build`。
- **`legion.von` 合同扩展**：`entry` 指定库模式入口；`artifact` 区分可执行与库 Wasm 包，并校验 `[export]` / `@main`；Windows 长路径下源码收集更可靠。
- **依赖声明**：`legion.von` 中的 path / git 依赖由 planner 解析并 checkout 到 `vendors/git/`。
- **VCC 辅助模块**：`@valkyrie-language/vcc/benchmark` 与 `/testing` 可用于对比参考实现与 `legion build` 产出的 Wasm 运行结果。

## 🐛 Bug Fixes

- 修复 `[export(case: ...)]` 等保留字作为命名属性键时无法解析的问题。

## ⚠️ Breaking Changes

- 平台 native collect 文件名统一为 `vcc.{triple}.node`（例如 `vcc.win32-x64-msvc.node`）。请通过 `@valkyrie-language/vcc` 解析路径，或重新安装对应 `vcc-*` 平台包。
- 库模式 Wasm 工程须在 `legion.von` 声明 `artifact: library` 并提供 `[export]` 导出入口。
