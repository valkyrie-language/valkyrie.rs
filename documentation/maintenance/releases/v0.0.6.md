## ✨ Features

- `@valkyrie-language/vcc` 新增 execution manifest 解析与校验（`run-contracts.txt` / `compile-evidence.txt`），宿主可在 invoke 前核对产物合同与编译证据。
- `vcc-napi` 暴露 Legion host API，Node 宿主可编程驱动 build/run，不再只能 spawn CLI。
- Legion 构建链路重构：`legion plan`、按 target 的 artifact 选择，以及独立的 `legion-workspace` 装配层。

## 🐛 Bug Fixes

- wasm capability 门禁恢复 bootstrap fixture 装配，修复 CI 在完整 `legion.tools` 闭包未贯通时无法产出 `vcc-unknown-wasm32` 的问题。
- VCC 宿主与测试对齐 `vcc` 二进制名及跨平台 run fixture 源码换行，避免 CI 与本地 span 漂移。
