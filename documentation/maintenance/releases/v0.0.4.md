## ✨ Features

- `legion` 默认启用 Nyar VM lane：可对 `.nyar` 做构建与运行，并把工作负载意图标志传入 nyar-vm。
- 无 `entry` 的 library 工程在 `legion build --target` 时合成构建目标，便于外部产物基准与库模式包。
- `vcc` 宿主在可用时走原生 N-API：支持 `legion` CLI argv / stdio 捕获，以及测试侧的 `spawnNativeLegion` 与 Nyar 入口辅助。
- Nyar 字节码侧补充可观察能力：`CallIntrinsic`、`CallImport`（替代 `CallNative`）、`ObjectNew` / `FieldGet` / `FieldSet` 与 layouts，以及执行清单中的合同版本字段。

## 🐛 Bug Fixes

- Nyar VM `legion run` 占位路径改用逻辑入口，避免错误入口名。
- 语义缓存在还原 MIR 未通过 `validate_module` 时拒绝复用，避免陈旧缓存导致错误产物。
