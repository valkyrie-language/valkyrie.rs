## ✨ Features

- `@valkyrie-language/vcc` 只保留正交的宿主能力：native N-API 绑定加载、wasm 子进程 helpers、execution manifest 解析，以及按产品划分的子路径导出（`./legion`、`./asgard`）。
- `@valkyrie-language/legion` 与 `@valkyrie-language/asgard` 各自持有 CLI（经 `@vmz/commander`），只依赖 `@valkyrie-language/vcc`，不再由 vcc 聚合命令入口。

## 🐛 Bug Fixes

- `@valkyrie-language/vcc` 的 execution manifest 解析改为同时接受 oak-von 的 `=` 与 `:` 对象条目分隔符，宿主可读取 `write_von_indented` 实际写出的 `run-contracts.txt`。
- `compile_source_snapshot` 只校验入口组唯一且位于最后，语义索引、选择与闭包摘要回归 Compiler，装配层不再重复规划语义闭包。

## ⚠️ Breaking Changes

- `@valkyrie-language/vcc` 不再聚合 CLI：原先从该包导入宿主 CLI 的调用方需改用具名子路径（`./legion`、`./asgard`）或产品包。
- `@valkyrie-language/legion`、`@valkyrie-language/asgard` 改为只依赖 `@valkyrie-language/vcc` 与 `@vmz/commander`，平台 collect 由 vcc 通过可选依赖装配。
