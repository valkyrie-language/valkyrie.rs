## ✨ Features

- Rust seed 原生可执行文件统一为 `vcc`（`cargo build -p legion` 产出 `target/*/vcc`）；`@valkyrie-language/vcc/testing` 的 `VCC_BIN` 解析同步更新。npm 用户 CLI 入口仍为 `@valkyrie-language/legion`。

## 🐛 Bug Fixes

- Legion CLI 的 build/run 日志与 execution manifest 输入改为工作区相对路径，便于跨机器复现与对比。
- VCC 宿主在 Legion CLI 失败时不再泄漏本机绝对路径。

## ⚠️ Breaking Changes

- 若脚本直接调用 `target/release/legion` 或 `legion.exe`，需改为 `target/release/vcc` / `vcc.exe`。
